# 人際小本本

魔羯人際風控筆記（INTJ）Android App。

目前版本：v1.0.2。此版讓所有儲存按鈕直接呼叫資料操作，不再依賴 WebView 表單送出；確認視窗也改為獨立按鈕流程。設定頁會顯示實際版本與儲存模式。

專案內的 `app/debug.keystore` 僅供側載測試版維持固定簽章，密碼為 Android 標準測試值 `android`，不可用於正式上架版本。

## 目前功能

- 新增人物：姓名、暱稱、電話、其他聯絡方式、認識日期、關係、標籤與備註。
- 起始分預設 80，可在設定修改，也可為個別人物調整。
- 五級風險顏色：0–40 紅、41–60 橘、61–80 綠、81–94 藍、95–100 紫。
- 人物總分與分類分數分開計算；內建信用、責任、財力、能力、相處，可新增、修改或停用分類。
- 事件可加分／扣分、指定一個或多個分類、標記重要／待追蹤並附照片。
- 金錢借貸：他欠我、我欠他、部分還款、到期與逾期判斷。
- 物品借貸：借出、借入、數量、型號／序號、估值、借出與歸還狀況。
- 借貸本身不會自動扣分；還款／歸還時可選擇是否同步建立評分事件。
- 姓名、電話、標籤、事件、物品及備註的關鍵字搜尋。
- 依總分、分類、借貸中或逾期狀態篩選。
- 細項以底部彈窗查看，首頁只顯示重要警示。
- 本機離線保存、JSON 備份／還原、單筆借貸 CSV 對帳明細。
- 4–8 位 PIN 介面鎖。

## 資料隱私

資料保存在 App 的本機 WebView 儲存區，不會主動連線或上傳。Android 備份已停用。PIN 是防止他人直接打開介面的基本保護，不代表資料已加密；換機或移除 App 前請先匯出 JSON 備份。

## 測試

```bash
npm test
npm run check
```

## Android 編譯

需求：JDK 17、Android SDK 35、Gradle 8.9。

```bash
gradle :app:assembleDebug
```

輸出位置：`app/build/outputs/apk/debug/app-debug.apk`

若放入 GitHub 新專案，推送至 `main` 後，內附的 GitHub Actions 會自動測試並產出可下載的 Debug APK。
