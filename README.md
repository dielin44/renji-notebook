# 人際小本本

魔羯人際風控筆記（INTJ）Android App。

目前版本：v1.1.1。新增共用人物自訂欄位、大頭照選區與原圖、備註捷徑、完整借貸歷史、還款更正、分級門檻、七種標籤外觀、標題自訂與原聲介紹，以及 Android 到期通知。

專案內的 `app/debug.keystore` 僅供側載測試版維持固定簽章，密碼為 Android 標準測試值 `android`，不可用於正式上架版本。

## 目前功能

- 新增人物：姓名、暱稱、電話、其他聯絡方式、生日、星座、血型、關係、標籤、大頭照與備註。
- 起始分預設 80，可在設定修改，也可為個別人物調整。
- 五級風險顏色：0–40 紅、41–60 橘、61–80 綠、81–94 藍、95–100 紫。
- 人物總分與分類分數分開計算；內建信用、責任、財力、能力、相處，可新增、修改或停用分類。
- 事件可加分／扣分、指定一個或多個分類、標記重要／待追蹤並附照片；重要事件會以金色卡片醒目顯示。
- 人物往來明細只顯示該人物全部事件，並分為加分與扣分兩頁；金錢與物品另以「借貸關係」顯示。
- 金錢借貸：他欠我、我欠他、部分還款、到期與逾期判斷；未結清卡片可直接記錄還款。
- 物品借貸：借出、借入、數量、型號／序號、估值、借出與歸還狀況。
- 借貸與還款／歸還都不加扣分。還款獨立保存在原借貸中，可確認後新增、修改或刪除，餘額由全部有效紀錄重新計算。已結清的原借貸仍保留。
- 姓名、電話、標籤、事件、物品及備註的關鍵字搜尋，首頁常用標籤可自行更換。
- 依總分、分類、借貸中或逾期狀態篩選。
- 首頁統計評分 90 分以上的優質人物與 40 分以下的劣質人物；細項以底部彈窗查看。
- 本機離線保存、顯示實際內部儲存路徑、JSON 備份／還原、單筆借貸 CSV 對帳明細。
- 4–8 位 PIN 介面鎖。
- 人物可改名、替換／移除照片；新大頭照保存原圖，卡片以可拖曳圓圈選定區域。
- 自訂欄位新增一次所有人物共用，內容各自填寫；備註可從人物查看頁直接修改。
- 優質／劣質名稱與門檻可修改，預設為 ≥90、≤40。
- 標籤可排序，外觀含經典、極光、霓虹、電光、熔岩、冰晶、曜金。
- 首頁標題短按播放上傳影片的原聲片段，長按修改主標題與副標題。
- 個別借貸可開啟到期日當地上午 9:00 的 Android 通知。系統省電可能延後送達；Android 13 以上需允許通知。重新開機、更新或變更時區後會重新排程，已結清或刪除的借貸會取消通知。

## 資料隱私

資料保存在 App 私有目錄中的原生原子檔案，不會主動連線或上傳。Android 備份已停用。PIN 是防止他人直接打開介面的基本保護，不代表資料已加密；換機或移除 App 前請先匯出 JSON 備份。

## 測試

```bash
npm test
npm run check
```

## Android 編譯

需求：JDK 17、Android SDK 35、Gradle 8.9。

```bash
gradle :app:assembleDebug
```

輸出位置：`app/build/outputs/apk/debug/app-debug.apk`

若放入 GitHub 新專案，推送至 `main` 後，內附的 GitHub Actions 會自動測試並產出可下載的 Debug APK。
